    Classroom Presentation Script & Teacher Viva Defense
    Classroom Cheatsheet

    Presentation Structure & Speaking Points

    1. Problem Definition

    "Traditional filters fail against zero-day short-lived links and psychological coercion. Attackers exploit fear (account suspension, power cuts) rather than system exploits."

    2. Multimodal Capability

    "The system unifies raw text NLP (TF-IDF), 14-parameter structural URL entropy analysis, and screenshot OCR image extraction into a single engine."

    3. Explainable AI (XAI) Novelty

    "Instead of opaque black-box outputs, the system derives log-odds coefficients to compute word-by-word feature attributions, explaining the exact deception triggers."

    4. Algorithmic Comparison

    "Random Forest achieved 98.2% accuracy and 1.5% FPR, while Logistic Regression achieved 97.4% with optimal mathematical interpretability."

    Key Examination Viva Questions

    Q: Why not use Large Language Models (LLMs) like GPT-4?

    Defense: "Commercial LLMs induce network latency (>2s), require recurring financial API costs, and transmit confidential user messages to third-party endpoints. Our Scikit-Learn TF-IDF pipeline executes locally in under 40ms with zero cost."

    Q: What is Shannon Entropy in URL Analysis?

    Defense: "Shannon Entropy quantifies character randomness: \(H = -\sum p(c) \log_2 p(c)\). Phishing kits employ Domain Generation Algorithms (DGA) resulting in elevated entropy (> 4.2), allowing detection of zero-day URLs."

    Q: What is your False Positive Rate (FPR)?

    Defense: "Random Forest achieved an FPR of 1.5% and Logistic Regression achieved 2.2%, preventing legitimate transactional receipts and administrative alerts from false flags."
